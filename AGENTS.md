## Agent skills

### Issue tracker

Issues e PRDs vivem no GitHub Issues deste repositório; use a CLI `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Usar os cinco nomes padrão: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human` e `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` e `docs/adr/` na raiz. See `docs/agents/domain.md`.
