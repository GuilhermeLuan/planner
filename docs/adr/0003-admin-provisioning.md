# Provisionamento administrado de contas

Status: substituída pela ADR 0023

Uma instalação é inicializada por uma Conta administradora, que cria ou convida outras Contas. Não haverá auto cadastro público no MVP, reduzindo o risco de exposição acidental do servidor self-hosted. A Conta administradora também usa seu próprio Planner normalmente; administração é uma permissão adicional, não um tipo separado de pessoa.
